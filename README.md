A minimal tool to write BBCode reports with ease and either export as .txt or copy to clipboard. This tool was designed primarily for the needs of the Europe region in the political simulation game NationStates, but it can be customised at need.

## Installation
1) Clone the repository
```bash
git clone https://github.com/altairgigi/reporter.git
```

2) Install the dependencies
```bash
pip install -r requirements.txt
```

3) Run the tool with
```bash
#windows
python main.py
```
or
```bash
#linux/macos
python3 main.py
```

## Features
* **BBCode Formatter:** Easily get BBCode reports and either save them to a `.txt` file or copy them to the clipboard.
* **Minimal UI:** Everything at your hand to speed your reporting.

## Tech-Stack
* **Language:** Python (tested on v3.12)
* **Package Manager:** pip (v25.0.1)
* **UI Library:** CustomTKinter (v6.0-0)
